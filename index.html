跨设备同步 / 备份

答题记录默认只存在本机浏览器。开启同步后，点一次「立即同步」就会把本机记录合并写入一个 私有 GitHub Gist；在其他设备粘贴同一个 Gist ID 与 Token，拉取即可继续。 记录只存在你自己的 GitHub 账号里，不经过任何第三方服务器。

领取 Token 的三步

一次配置，长期可用
  • GitHub 右上角头像 → Settings → 左侧到底 Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
  • Note 随便填（如 npdp-sync），Expiration 选 90 天，只勾选 gist 这一项，其它一律不勾
  • 点 Generate，复制 ghp_ 开头的串，粘贴到上面的输入框 → 点「立即同步」。首次会自动创建一个私有 Gist，把生成的 Gist ID 记下来，在另一台设备填进去即可

Token 只保存在本机浏览器（localStorage），不会上传到任何地方；换电脑或清理浏览器数据后需要重新粘贴。「断开本机」只清除本机保存的 Token 与 Gist ID，云端记录不受影响。
